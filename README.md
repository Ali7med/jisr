# جسر — Jisr

**منصة منزل ذكي سحابية، عربية أولاً، بلا أجهزة إضافية.**
سيرفر مركزي يدير التكاملات والأتمتة، وتطبيق Flutter واحد للهاتف والويب، وطبقة تكاملات مفتوحة تبدأ بـ Tuya وتتوسّع لأي شركة.

> «افتح التطبيق، اربط حسابك، وتحكّم ببيتك من أي مكان — خلال خمس دقائق، بالعربي.»

## هيكل المستودع

</div>

```
jisr/
├── packages/
│   └── jisr_core/     النواة المشتركة (Dart خالص) — تُستخرج في المرحلة P0
├── apps/
│   ├── mobile/        ✅ تطبيق Flutter (أندرويد الآن، ويب في P2) — يعمل
│   ├── server/        ⏳ السيرفر (Dart shelf) — المرحلة P1
│   └── web/           محجوز (القرار الحالي: الويب من apps/mobile)
└── docs/              الدراسة · الهيكلية · خارطة الطريق · القرارات
```

## القواعد الحاكمة

1. `jisr_core` لا تعرف Flutter — شرط عملها على السيرفر.
2. لا اسم شركة خارج `integrations/`.
3. ما لا نفهمه يُعرض خاماً، لا يُخفى.
4. كل رسالة خطأ عربية وتشرح ما العمل.
5. الوضع المباشر لا يُكسر أبداً — السيرفر إضافة، ليس شرطاً.
6. الأسرار لا تدخل git ولا السجلّات.
