# قرارات معمارية (ADR)

سجلّ **لماذا** بُني المشروع بهذا الشكل. كل ملف يوثّق قراراً واحداً وبدائله المرفوضة.

## القاعدة
- ADR **لا يُعدَّل** بعد اعتماده. لو تغيّر القرار، اكتب ADR جديداً يَنسَخه واذكر ذلك في كليهما.
- كل قرار يغيّر بنية الكود أو يقيّد الخيارات المستقبلية يستحق ADR.

## القالب

```markdown
# ADR-XXXX — <العنوان>

**الحالة:** معتمد | مرفوض | مَنسوخ بـ ADR-YYYY
**التاريخ:** YYYY-MM-DD

## السياق
ما المشكلة؟ ما القيود؟

## القرار
ما اخترناه، بجملة واضحة.

## البدائل المرفوضة
| البديل | لماذا رُفض |

## النتائج
### إيجابية
### سلبية
### ما يُبطل هذا القرار
```
