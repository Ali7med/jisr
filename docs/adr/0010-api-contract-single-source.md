# ADR-0010 — عقد API كمصدر حقيقة واحد

**الحالة:** ✅ معتمد
**التاريخ:** 2026-09-02

## السياق

المنظومة بلغتين ([ADR-0008](0008-typescript-stack.md)): سيرفر وويب TypeScript، وهاتف Dart. `packages/shared` يضمن أن تغيير حقل يكسر البناء فوراً — **للسيرفر والويب فقط**. الهاتف سيكتب نماذجه يدوياً (P3.3) بلا أي رابط آلي بالعقد، فأي انحراف يُكتشف وقت التشغيل عند المستخدم، لا وقت البناء — وهو بالضبط الخطر الذي تفاخر 0008 بإغلاقه للويب.

قيدان يحكمان الحل:
- [ADR-0005](0005-no-code-generation.md): بلا توليد كود في الهاتف.
- Fastify يعرّف كل مسار بـ JSON Schema أصلاً — العقد موجود في الكود فعلاً، ينقصه التصدير فقط.

## القرار

1. **OpenAPI مولَّد آلياً من مخططات Fastify** (`@fastify/swagger`) هو مصدر الحقيقة الوحيد للعقد. الملف الناتج (`packages/shared/openapi.json`) يُلتزم به في git — أي تغيير عقد يظهر في المراجعة كـ diff صريح.
2. **جانب Dart يُثبَّت باختبارات عقد، لا بتوليد كود**: اختبارات السيرفر تُنتج **fixtures ذهبية** (استجابات JSON حقيقية لكل نموذج) تُلتزم في المستودع، واختبارات Flutter تحلّلها بـ `fromJson` اليدوي. حقل يتغيّر في السيرفر ⇒ الـ fixture يتغيّر ⇒ اختبار Dart يفشل في CI قبل الدمج.
3. النماذج اليوم سبعة فقط — هذا الحجم يجعل اختبارات العقد كافية ويُبقي 0005 سليماً حرفياً.

## البدائل المرفوضة

| البديل | لماذا رُفض |
|---|---|
| **توليد DTOs لـ Dart من OpenAPI** | يخالف [ADR-0005](0005-no-code-generation.md)؛ يصبح مبرَّراً إذا كبرت النماذج (بند إبطال 0005 نفسه: ~15 نموذجاً) — حينها يُكتب ADR يعدّل نطاق 0005 صراحةً لا يتجاوزه بصمت |
| **المزامنة اليدوية بلا أي رابط** (الوضع الحالي) | انحراف صامت يظهر عند المستخدم لا في CI |
| **GraphQL** | يحلّ مشكلة لا نملكها (استعلامات مرنة) بكلفة عقد أثقل ومكتبات إضافية في الأطراف الثلاثة |
| **gRPC / protobuf** | توليد كود إلزامي في كل الأطراف (يصادم 0005) واحتكاك مع الويب وWebSocket |

## النتائج

### إيجابية
- كسر العقد يُكتشف في CI قبل الدمج — في الأطراف الثلاثة لا في اثنين
- `openapi.json` الملتزم به = توثيق API حيّ بلا جهد إضافي
- 0005 يبقى سليماً: لا `build_runner` ولا ملفات مولّدة في الهاتف

### سلبية
- انضباط جديد: كل نموذج يحتاج fixture ذهبياً واختبار تحليل مقابله في الهاتف
- الـ fixtures بيانات ثابتة — لا تغني عن اختبار تكامل حقيقي دوري ضد سيرفر يعمل

### ما يُبطل هذا القرار
تجاوز النماذج ~15، أو تكرار أخطاء تحليل في الهاتف رغم الاختبارات ⇒ الانتقال لتوليد DTOs بـ ADR جديد يعدّل نطاق 0005 (وهو نفسه بند إبطال 0005).
