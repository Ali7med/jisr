# ADR-0011 — تثبيت الـ Monorepo وأدوات الـ workspace

**الحالة:** ✅ معتمد
**التاريخ:** 2026-09-02

## السياق

قرار الـ Monorepo وُلد في [ADR-0007](0007-dart-server-monorepo.md)، ثم نُسخ 0007 **بالكامل** بـ [ADR-0008](0008-typescript-stack.md) الذي عالج لغة السيرفر والويب ولم يعالج بنية المستودع — فبقي الـ Monorepo معمولاً به ([الهيكلية § 2](../02-architecture.md#٢-هيكل-المستودع)) بلا قرار معتمد يسنده، وبلا تحديد أدواته لجانب TypeScript، وبلا تثبيت إصدار Node.

## القرار

1. **الـ Monorepo يبقى**: `packages/shared` + `apps/server` + `apps/web` + `apps/mobile` في مستودع واحد — عقد الـ API المشترك وقاعدة «التوثيق يتغيّر مع الكود في نفس الكومِت» يفترضانه أصلاً.
2. **pnpm workspaces** لإدارة حزم TypeScript الثلاث. بلا turborepo/nx الآن — تطبيقان وحزمة لا يحتاجون طبقة تنسيق.
3. **تطبيق Flutter خارج الـ workspaces**: `apps/mobile` يدير نفسه بـ pub — لا جسر مصطنع بين النظامين.
4. **Node 24 LTS** مثبّت في `.nvmrc` وحقل `engines` — ويُرقّى مع كل LTS جديد بكومِت واعٍ لا عرضياً.
5. **CI واحد بمسارات مفلترة**: تغيّر في TS ⇒ `tsc --noEmit` + `vitest`؛ تغيّر في `apps/mobile` ⇒ `flutter analyze` + `flutter test`.

## البدائل المرفوضة

| البديل | لماذا رُفض |
|---|---|
| **مستودعات منفصلة** | مطوّر واحد يقفز بين ثلاثة مستودعات، وعقد `shared` يتطلّب نشر إصدارات — عبء تنسيق بلا مقابل |
| **npm / yarn workspaces** | تعمل، لكن pnpm أسرع وأصرم في عزل الاعتماديات وأوسع تبنّياً |
| **turborepo / nx من اليوم الأول** | كلفة تعلّم وضبط مقابل توفير ثوانِي بناءٍ لا نعاني منها — يُضاف عند الألم لا قبله |
| **melos لضمّ Flutter إلى الـ workspace** | طبقة إضافية لتوحيد شكلي؛ عندنا تطبيق Flutter واحد لا حزم Dart متعددة |

## النتائج

### إيجابية
- قرار البنية لم يعد يتيماً، وأدوات الجانب TS محسومة
- `pnpm install` واحد يجهّز السيرفر والويب والعقد معاً
- ترقية Node موثّقة ومقصودة — لا مفاجآت في Dockerfile وCI

### سلبية
- الـ CI يحتاج فلترة مسارات كي لا يبني كل شيء عند كل تغيير
- نظامان للاعتماديات (pnpm + pub) يعيشان جنباً إلى جنب — مقبول واعياً

### ما يُبطل هذا القرار
فريق يكبر، أو أوقات بناء تؤلم، أو تطبيقات تتكاثر ⇒ يُعاد تقييم طبقة تنسيق (turborepo أو ما يكافئها) بـ ADR جديد.
