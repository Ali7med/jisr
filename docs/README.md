## قواعد صيانة التوثيق

1. **الكود يتغيّر ⇒ التوثيق يتغيّر في نفس التعديل.**
2. **قرار معماري جديد ⇒ ملف ADR جديد** — القديم لا يُعدَّل بل يُنسَخ بإحالة متبادلة.
3. **مهمة تُنجَز ⇒ تُعلَّم في [03 — خارطة الطريق](03-roadmap.md)** مع سطر بالتاريخ.
4. الوثيقة تجيب على **لماذا**؛ الكود يقول **كيف**. لا تكرّر الكود في نص.
5. توثيق داخلي خاص بتطبيقٍ ما (تفاصيل شاشة، ودجت) يعيش قرب كوده لا هنا — هذا المجلد لمستوى **المنظومة**.
