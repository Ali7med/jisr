## ٢. هيكل المستودع

```
D:\Apps\Projects\jisr\
├── packages/
│   └── shared/          ★ TypeScript — أنواع وعقود API يشترك بها السيرفر والويب
│
├── apps/
│   ├── server/          ★ Fastify · TypeScript — عقل المنظومة
│   │   └── src/
│   │       ├── api/            مسارات REST
│   │       ├── auth/           JWT · Argon2 · صلاحيات
│   │       ├── realtime/       WebSocket + مستهلك رسائل Tuya
│   │       ├── automations/    محرّك القواعد (BullMQ)
│   │       ├── integrations/   ★ Integration · tuya/ · registry
│   │       └── db/             Prisma schema + migrations
│   │
│   ├── web/             ★ Next.js · React — لوحة الإدارة
│   │   └── src/               ربط الحسابات · بانِي الأتمتة · المستخدمون · السجلّ
│   │
│   └── mobile/          ✅ Flutter — موجود، يتحوّل لعميل رفيع
│       └── lib/
│           ├── ui/            ★ يبقى كما هو — الواجهة الديناميكية من القدرات
│           ├── domain/        نماذج مبسّطة (Device · Capability) من API
│           └── data/          ★ يُستبدل: JisrApiClient بدل تكامل Tuya
│
└── docs/                الدراسة · الهيكلية · خارطة الطريق · القرارات
```

> **ما يُحذف من الهاتف:** `data/integrations/tuya/` بالكامل + التوقيع + إدارة التوكن + تخزين الأسرار.
> **ما يبقى ويُعاد استخدامه:** كل مجلد `ui/` — الشاشات والودجتات الديناميكية للقدرات، وهي أثمن ما بُني.

## ٣. السيرفر

| الوحدة | المسؤولية | التقنية |
|---|---|---|
| **REST API** | `/auth` · `/accounts` · `/devices` · `/devices/{id}/commands` · `/automations` · `/history` | Fastify + JSON Schema |
| **طبقة التكاملات** | عقد `Integration` وتنفيذاته — نقل مفاهيمي لما بُني بـ Dart | TypeScript |
| **WS Push** | قناة لكل عميل؛ يدفع `device_state_changed` فور وصوله | `@fastify/websocket` |
| **مستهلك رسائل Tuya** | اشتراك دائم يستقبل تغيّرات الأجهزة لحظياً | **SDK رسمية من Tuya لـ Node.js** |
| **محرّك الأتمتة** | مشغّل (حالة/وقت/شروق) + شرط + إجراء، يعمل ٢٤/٧ | BullMQ |
| **مسجّل التاريخ** | كل تغيّر حالة → قاعدة البيانات → رسوم بلا حدود Tuya (٧ أيام) | Prisma + PostgreSQL |
| **المصادقة** | مستخدمون · JWT + refresh · صلاحيات لكل فرد عائلة | `jose` + `argon2` |
| **الإشعارات** | Push عند أحداث حرجة (دخان، تسرّب) | `firebase-admin` |

**نموذج البيانات المحوري يُنقل كما هو:** `Integration` · `IntegrationInfo` (تُبنى منه شاشة الربط ديناميكياً) · `Capability` (`toggle` · `range` · `mode` · `text`) · `Device` · `DeviceCategory`. التصميم مثبت وموثّق في [ADR-0003](adr/0003-dynamic-ui-from-specifications.md).

## ٤. لوحة الويب

**Next.js + React + TypeScript** — تشارك `packages/shared` مع السيرفر، فتغيير عقد API يكسر البناء فوراً في الطرفين.

| القسم | الوظيفة |
|---|---|
| **ربط الحسابات** | اختيار الشركة → نموذج يُبنى من `IntegrationInfo.fields` (نفس مبدأ التطبيق) → اختبار الاتصال |
| **بانِي الأتمتة** | «إذا … و… فـ …» بصرياً بالعربي — **بلا YAML إطلاقاً** ([الدراسة § 4](01-study.md)) |
| **المستخدمون** | دعوة أفراد العائلة، صلاحيات لكل جهاز |
| **السجلّ والرسوم** | تاريخ القراءات، استهلاك الطاقة |
| **الأجهزة** | عرض وتحكّم كامل (نفس قدرات الهاتف) |

## ٥. تطبيق الهاتف

**عميل رفيع** ([ADR-0009](adr/0009-server-mandatory-thin-client.md)): لا كود تكاملات، لا أسرار، لا اتصال بأي شركة.

```
lib/data/jisr_api_client.dart   ← REST + WebSocket إلى سيرفرنا
lib/ui/                          ← يبقى كما هو تماماً
```

- شاشة تسجيل دخول بدل شاشة إدخال مفاتيح Tuya
- **لا polling** — يستمع لـ WebSocket
- شاشة التفاصيل تبقى ديناميكية من `Capability` — لكن القدرات تصل من سيرفرنا

## ٦. تدفّقات البيانات

**تحكّم:**
```
الهاتف ──POST /devices/tuya:abc/commands──▶ السيرفر ──▶ Tuya ──▶ الجهاز
Tuya ──رسالة فورية──▶ السيرفر ──WS──▶ كل أجهزة العائلة  (< ٢ ثانية)
```

**تغيّر خارجي (ما كان مستحيلاً بلا سيرفر):**
```
أحدهم أطفأ المصباح يدوياً → Tuya → السيرفر → WS → هاتفك يتحدّث لحظياً
```

**أتمتة:**
```
حساس الحرارة > 30° → السيرفر: قاعدة مطابِقة → تشغيل المكيّف + إشعار Push
```

**سقوط السيرفر:**
```
التطبيق يعرض آخر حالة معروفة من الكاش المحلي + «آخر تحديث قبل ١٢ دقيقة»
عناصر التحكّم معطّلة · رسالة عربية: «تعذّر الاتصال بجسر — نحاول مجدداً»
التحكّم متوقف (قرار واعٍ — ADR-0009 · نموذج العطل في ADR-0014)
```

## ٧. الأمان

| الطبقة | الإجراء |
|---|---|
| أسرار التكاملات | AES-GCM في القاعدة بمفتاح من متغيّر بيئة خارجها — تسريب dump لا يكشفها. **حدّ معروف:** المفتاح يعيش على نفس المضيف، فاختراق الـ VPS يكشف المفتاح والبيانات معاً. يُرقّى إلى KMS/Vault عند أول من يتحقّق: خروج القاعدة إلى مضيف منفصل، أو تجاوز ١٠٠ حساب مربوط |
| **الهاتف** | **لا يحمل أي سرّ إطلاقاً** — يحمل JWT فقط. الثغرة القديمة ([ADR-0002](adr/0002-direct-connection-with-abstraction.md)) أُغلقت |
| المصادقة | JWT قصير العمر + refresh · كلمات المرور Argon2 |
| النقل | HTTPS/WSS فقط — Caddy بشهادات تلقائية |
| الصلاحيات | كل طلب يُفحص: هل هذا الجهاز ضمن أجهزة هذا المستخدم/العائلة؟ |
| التشغيل | **Rate limiting عام على كل المسارات** (`@fastify/rate-limit`) مع سقف أشدّ على `/auth` · السجلّات لا تطبع أسراراً أبداً |
| تدوير المفاتيح | مفتاح التشفير وأسرار JWT قابلة للتدوير بلا توقّف: إعادة تشفير تدريجية وقبول التوكنات القديمة حتى انتهائها |

## ٨. النشر

| البند | القرار |
|---|---|
| الحاويات | Docker Compose: `server` + `web` + `postgres` + `caddy` |
| الاستضافة | **Hetzner CX22 (2 vCPU · 4GB) ≈ €4.59/شهر + Coolify مجاني** — يستوعب المنظومة بمساحة واسعة |
| النسخ الاحتياطي | `pg_dump` يومي خارج السيرفر — **و«تمرين استعادة» ربع سنوي موثّق**: نسخة لم تُختبَر استعادتها ليست نسخة |
| المراقبة | `/health` + تنبيه عند السقوط — **إلزامي**، فالسيرفر صار نقطة فشل وحيدة |
| **هدف التوفّر** | **99.5% شهرياً معلن + صفحة حالة عامة** ([ADR-0014](adr/0014-availability-target.md)) — وعتبة رقمية تُفعّل إعادة النظر في [ADR-0009](adr/0009-server-mandatory-thin-client.md) |
| الاستعادة من الصفر | `docs/runbook.md`: نسخة احتياطية ← VPS جديد ← DNS. يُكتب في P2 ويُختبر مع كل تمرين استعادة — علاج مخاطرة «الشخص الواحد» |
| بيئة التجريب | لا staging منفصل الآن (قرار واعٍ لتوفير الكلفة)؛ الحماية: هجرات قابلة للتراجع + نشر خارج أوقات الذروة + `/health` يوقف النشر الفاشل |
| CI | `tsc --noEmit` + `vitest` للسيرفر والويب · `flutter analyze` + `flutter test` للهاتف |

## ٩. قواعد ثابتة

1. **لا اسم شركة خارج `server/src/integrations/`** — السجلّ هو المكان الوحيد الذي يذكرها.
2. **الهاتف والويب لا يعرفان أي شركة** — يستهلكان `Device` و`Capability` الموحّدين فقط.
3. **ما لا نفهمه يُعرض خاماً، لا يُخفى** — على الثلاثة.
4. **كل رسالة خطأ عربية وتشرح ما العمل.**
5. **عقود API في `packages/shared` فقط** — لا تعريف نوع مكرّر بين السيرفر والويب.
6. **الأسرار لا تدخل git ولا السجلّات** — على كل المستويات.
7. **إضافة شركة جديدة = ملف تكامل واحد + سطر في السجلّ.** لا شاشة جديدة في الهاتف ولا في الويب.
